# Kanagala Balarama Krishna — Memorial Website

Phase 01–03 foundation:

- React
- Vite
- Tailwind CSS v4
- Motion for React
- Warm Editorial Heritage design system
- Responsive hero
- Authentic transparent portrait slot
- Reduced-motion support
- Initial welcome transition section

## Requirements

Use a current Node.js version compatible with the installed Vite release. Current Vite documentation requires Node.js 20.19+ or 22.12+.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Add the hero image

Place the final transparent PNG at:

```text
public/images/father.png
```

The code does not alter or regenerate the photograph.
